# Иконка и исправление кадрирования

Дополнение к комплекту v2: основную игру и графику повторно не содержит.

- game_icon.png — исходная квадратная иконка.
- game_icon.ico — многоразмерная Windows-иконка: 16, 24, 32, 48, 64, 128, 256 px.
- CODEX_TASK.md — задача для изменения текущей сборки: скрыть нижний срез персонажей во всех состояниях, сохранить подложку при выборе и подключить иконку.

Передайте этот комплект Codex и попросите выполнить CODEX_TASK.md в существующем проекте. Исходники пользовательской сборки здесь не изменялись. Сам файл ICO проверен на чтение всех размеров; отображение в Ren'Py и Windows требует проверки после подключения и сборки.
