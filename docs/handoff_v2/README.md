# Комплект для доработки новеллы — v2

Распаковать ВСЕ архивы olya_codex_handoff_v2_XX.zip в одну папку. Каждый архив обычный самостоятельный ZIP; специальные программы для многотомных архивов не нужны. Части дополняют друг друга и не требуют старых архивов из переписки.

Передать Codex полученную папку olya_codex_handoff_v2 вместе с доступом к уже собранному Ren'Py-проекту. Первым прочитать START_PROMPT.md.

Приложены все выбранные ассеты: 89 сценических PNG (74 спрайта, 15 фонов), 65 UI PNG, семь статических TTF с лицензиями, один музыкальный OGG, ссылки на выбранные оригинальные темы, сюжетная справка, инструкции и перечни файлов. Это исходный комплект для доработки, НЕ готовая запускаемая игра и НЕ копия последней сборки пользователя. Из пользовательской сборки был предоставлен только ART_TODO.md.

Стрэндж остается в игре с двумя позами; требование отдельной эмоции сомнения снято. Недостающие оригинальные аудиотемы не заменены фиктивными файлами. Подробности — START_PROMPT.md и ART_STATUS.md.

Не переносить файлы поверх репозитория вслепую: в нем уже могут быть нормализованные изображения, работающие screens и более свежий сценарий. Старый пример интерфейса лежит в references с расширением .example, чтобы он не запускался автоматически. Снимок старого ART_TODO сохранен в docs только для истории; он уже не описывает текущее наличие графики.

Сценическая графика компактная: уменьшена палитра до 256 цветов без изменения разрешения, точность цветов/полупрозрачности снижена. Оригинальные UI и шрифты сохранены. Это позволило соблюсти ограничения передачи: меньше 20 МБ на каждый ZIP и меньше 50 МБ суммарно.
