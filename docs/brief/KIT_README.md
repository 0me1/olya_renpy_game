# Как передать комплект в Codex

1. Распаковать архив в папку проекта или приложить его к задаче Codex.
2. Попросить: «Прочитай START_PROMPT.md полностью и выполни задачу. Сначала проверь ASSETS.json и CAST_AND_ART.md. Используй приложенные файлы, сохрани сюжет и визуальные темы. Не выдавай отсутствующие ассеты за готовые».
3. START_PROMPT.md — основной переносимый промпт, он не требует истории этого чата.
4. ASSETS.json — перечень сценических PNG. game/gui/worlds — отдельные UI PNG. game/world_ui.rpy — интеграционный пример из прошлого комплекта.
5. Это исходные материалы для сборки, а не запускаемый Ren'Py-проект. Не открывать эту папку как готовую игру до реализации.

Создано: 32 спрайта Оли, 3 базовых второстепенных персонажа, 14 фонов, 65 UI PNG. Для остальных основных героев пока есть спецификация, но нет графики. В промпте отдельно указано, как обрабатывать этот недостаток. Новые сюжетные подробности глав — рабочая разработка, которую можно редактировать.


Компактная версия: сценические PNG переведены в индексированную палитру до 192 цветов. Разрешение сохранено, точность цветов и полупрозрачности снижена. Это не сжатие без потерь. UI оставлен исходным. Распаковать ВСЕ архивы в одну папку: они дополняют друг друга.
