# В порядке перевода

Персональная фанатская визуальная новелла на Ren'Py 8, подарок Оле. Работает без сети и монетизации. Оля засыпает в кабинете и путешествует через Вистерия-Лейн, Манхэттен, South Park, Minecraft, The Sims и Marvel. В каждом мире можно остаться; дома ждет поздравление с днем рождения.

## Открыть исходники

1. Установить Ren'Py SDK 8.5.3 или совместимую версию Ren'Py 8.
2. Распаковать папку проекта целиком. В ней должны лежать README.md и папка game.
3. В Launcher открыть Preferences → Projects Directory и выбрать родительскую папку проекта.
4. Выбрать olya_renpy_game и нажать Launch Project. Размер виртуального холста — 1920 × 1080; окно масштабируется, есть полный экран.

SDK уже установлен в текущей облачной среде отдельно от Git. В проекте нет абсолютных путей или зависимости от облачного сервера. Для разработки достаточно SDK; системный Python нужен только для дополнительных проверок.

## Управление

Enter / Пробел / щелчок — следующая реплика. Стрелки и Tab — фокус кнопок, Enter — выбор. Esc / правая кнопка — меню. Колесо вверх / Page Up — откат. Ctrl — пропуск, H — скрыть интерфейс, F — полный экран. История, авто, сохранение, загрузка и настройки доступны в нижней панели. Перед каждым решением остаться можно сохранить игру.

Коллекция хранится отдельно от текущего прохождения и не стирается при новой игре. Просмотр эпилога из коллекции не изменяет сюжетные переменные активной игры. Все финалы равноценны. Условия — в ROUTES.md.

## Проверки разработчика

В каталоге проекта, с указанием своего пути к SDK:

```bash
export RENPY_SDK=/path/to/renpy-8.5.3-sdk
./tools/run_checks.sh
```

На сервере без экрана нужен работающий X-дисплей и переменная DISPLAY. В текущей среде используется Xorg с dummy-драйвером; это виртуальный экран для тестов, удаленный рабочий стол не настроен. Для беззвучного запуска можно задать `SDL_AUDIODRIVER=dummy`. Проект не требует установки пакета `renpy` через pip: движок и Python входят в SDK.

Для изолированного каталога сохранений SDK поддерживает `RENPY_PATH_TO_SAVES`; перед запуском создать в нем подпапку `tokens`. Не добавлять ключи подписи сохранений и игровые сейвы в Git или архив исходников.

Отдельные команды:

```bash
"$RENPY_SDK/renpy.sh" "$PWD" lint
"$RENPY_SDK/renpy.sh" "$PWD" test routes
"$RENPY_SDK/renpy.sh" "$PWD" test interface --overwrite-screenshots
"$RENPY_SDK/renpy.sh" "$PWD" test layout
```

Графические проверки запускать последовательно: одновременные прогоны на общем X-дисплее мешают фокусу и кликам. Набор routes проходит три комбинации пути домой, шесть ранних финалов и шесть возвратов. Interface проверяет все темы, меню, галерею, новую игру и сохранение/загрузку через переход. Layout измеряет реплики средствами движка. Реальные результаты и границы проверки — в TEST_REPORT.md.

## Сборка

В Launcher: Build Distributions → Windows / Linux. Через командную строку:

```bash
"$RENPY_SDK/renpy.sh" "$RENPY_SDK/launcher" distribute "$PWD" --package pc --destination ../artifacts
```

Windows EXE запускается после распаковки всей сборки, а не отдельно от ее файлов. Нативную работу EXE нужно проверять на Windows; Linux-проверка не заменяет ее.

## Состав и ограничения

Около 6,9 тысячи слов во всех ветках и эпилогах; 45–60 минут — авторский ориентир, не измеренное время чтения. Весь русский игровой текст использует е вместо буквы с двумя точками.

Сохранены все 114 исходных PNG комплекта. Только у Сьюзан, Бри и Габи есть второстепенные спрайты. По решению пользователя остальные главы пока идут без спрайтов собеседников; их сюжетные сцены реализованы. Аудиофайлов нет, игра работает в тишине. Полный художественный статус — ART_TODO.md. Это рабочая версия с черновой графикой.

Исходное задание и манифест сохранены в docs/brief. Файлы игры находятся в game; SDK, сейвы, результаты тестов и архивы в репозиторий не входят. Авторские права на исходные миры и персонажей принадлежат их владельцам; проект предназначен для личного подарка.
