# Скачать версию 0.2.0

- [Игра для Windows и Linux](https://github.com/0me1/olya_renpy_game/raw/refs/heads/main/downloads/V_Poryadke_Perevoda-0.2.0-pc.zip).
- [Исходники проекта](https://github.com/0me1/olya_renpy_game/raw/refs/heads/main/downloads/olya_renpy_game-0.2.0-source.zip).
- [Отчет интеграции и проверок](../INTEGRATION_REPORT.md).
- [Контрольные суммы SHA-256](SHA256SUMS-0.2.0.txt).

Распаковать весь PC-архив, затем запустить V_Poryadke_Perevoda.exe на Windows или .sh на Linux. Исходники открываются в Ren'Py Launcher. В этой версии подключены все собеседники, семь шрифтов, домашний праздничный фон и лицензированная музыка обычного мира.

Все 121 проверки исходного проекта прошли; четыре дополнительные проверки прошли собственным Linux-рантаймом сборки. Windows EXE собран, нативно на Windows не проверялся. Оригинальные темы остальных миров не приложены; там пока тишина. Для версии 0.2.0 рекомендуется новая игра, совместимость прежних сейвов не проверена.

Архив исходников соответствует коммиту `9cdc10efa955415e5ae5f9b01ddb36e8212f72de` и не содержит downloads, .git, кеши и сейвы.
